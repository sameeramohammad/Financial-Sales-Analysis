# 📊 Financial Sales Analysis

An end-to-end financial sales analysis project developed as part of the **Beeskilled Data Science Internship**.

## 🎯 Project Overview

This project analyzes financial sales data to identify business trends, evaluate product and customer segment performance, and generate data-driven business insights.

The project follows an end-to-end data analysis workflow using **Python, Microsoft Excel, and Microsoft Power BI**.

## 🎯 Objectives

- Analyze sales and profitability performance
- Identify high-performing countries and products
- Evaluate customer segment performance
- Analyze monthly sales trends
- Understand the impact of discount bands on profit
- Create interactive dashboards for business analysis

## 📂 Dataset

The dataset contains financial sales information across different:

- Countries

- Discount Bands
- Months

- Verifying data types and column names

## 🔍 Business Questions

The project answers the following questions:

1. Which country generated the highest profit?
2. Which product generated the highest profit?
3. Which segment performed the best?
4. What is the monthly sales trend?
5. How do discount bands affect profit?

## 💡 Key Insights

- **France** generated the highest overall profit.
- **Paseo** was the most profitable product.
- **Government** was the highest-profit customer segment.
- **October** recorded the highest monthly sales.
- Lower discount bands generated higher profits compared with higher discount bands.

## 📌 Business Recommendations

- Increase focus on high-performing products such as Paseo.
- Study successful sales strategies observed in France and apply relevant approaches to other regions.
- Investigate the negative profitability of the Enterprise segment.
- Optimize discount policies to improve profitability while maintaining sales performance.
- Improve marketing and inventory planning during peak sales months.
